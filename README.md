# Gherkin-Cucumber-e-Cypress
Entender a função de cada ferramenta.

## Tecnologia	Responsabilidade

**Gherkin	Descreve o comportamento esperado
Cucumber	Interpreta os cenários e associa cada passo ao código
Cypress	Executa as ações no navegador e verifica os resultados**

## O fluxo é:
**Gherkin**

*Dado que estou na página de login*

**Cucumber**

*Localiza a implementação de cada passo*

**Cypress**

*Executa as ações e valida o resultado*
