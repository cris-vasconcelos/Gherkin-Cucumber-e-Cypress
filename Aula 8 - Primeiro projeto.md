## Criando uma pasta
**Abra o terminal**

Execute:
```
mkdir -p ~/Documentos/cypress-cucumber

```
**Entre na pasta**
```
cd ~/Documentos/cypress-cucumber
```
**Abra o projeto**
```
code .
```

## O que fizemos?
- mkdir: criou a pasta.
- -p: criou também a pasta Projetos, caso ainda não exista.
- cd: entrou na pasta.
- code .: abriu a pasta atual no VS Code.
