# Como vai ficar a estrutura
```
cypress-cucumber/
├── cypress/
│   └── e2e/
│       └── login.feature
├── cypress.config.js
├── package.json
└── package-lock.json
```
Para o nosso curso prático de **automação +cucumber+ javaScript**, vamos precisar dos seguintes recursos:

  0.          Ferramenta         |	       Finalidade
  1.        	Node.js	               Executar JavaScript no ambiente local.
  2.        	npm	                   Instalar e gerenciar bibliotecas.
  3.        	Cypress        	       Automatizar testes no navegador.
  4.        	Cucumber               Preprocessor	Integrar arquivos Gherkin (.feature) ao Cypress.
  5.      Visual Studio Code	       Editar os arquivos do projeto.
  6.     Google Chrome ou Chromium	 Navegador para executar os testes.
  7.	        Git	                       Versionar o projeto.
  8.	        GitHub	               Publicar seu projeto e documentar seu aprendizado.


## Nossa sequência de configuração
1. Verificar Node.js, npm, Git e VS Code.
2. Instalar ou atualizar o Node.js, se necessário.
3. Criar a pasta do projeto.
4. Instalar Cypress.
5. Instalar e configurar o Cucumber.
6. Criar nosso primeiro arquivo .feature.
7. Criar os Step Definitions em JavaScript.
8. Executar o primeiro teste automatizado.
9. Documentar e publicar no GitHub.
